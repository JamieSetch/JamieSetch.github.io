NERVE: nervelabs

A spiking neural network IDE for robotic control. Scientists design networks on a canvas, simulate them on NEST, NEURON or Brian2 with an explicit check of how faithfully each engine runs each neuron model, and connect them to robots through ROS 2. I lead a team of four engineers building it.

2025–present · Research software

NERVE: blackbox

Hardware and software that let a person control a robot live from their own EEG and EMG signals.

2025–present · Hardware

Multipurpose BCI Controller

A real-time EEG brain–computer interface that turns neural signals into commands. It runs the whole pipeline (preprocessing, feature extraction, CNN training and live inference) on OpenBCI hardware using Python and BrainFlow.

2025 · Brain–computer interface

Dream MCP

A full-stack TypeScript MCP server that gives AI agents a persistent memory across sessions. It tracks repositories incrementally, summarises project state to fit an LLM's context window, learns preferences weighted by how often they come up, and syncs with Obsidian.

2026 · Software

AI CV Assistant

An AI assistant for writing CVs, built during the Newcastle University I-Lab internship and rolled out to support more than 5,000 students in 2025.
